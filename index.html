AgroAI — Sustainable Farming Platform

An AI-powered platform that helps farmers monitor crop health in real time. I designed the dashboard layout around one constraint: the end users are not technical, so the interface had to translate IoT sensor data and ML predictions into something a non-technical farmer could act on at a glance.

ProblemRaw sensor + ML output is unreadable to a non-technical user.
ApproachSimplified dashboard hierarchy: status → alert → recommended action.
